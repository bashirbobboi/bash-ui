# Portfolio images

Gallery examples from the author's portfolio site, not bundled into the
installable React source. Components accept image URLs so consumers can use
their own files.

`doodle-still.png` is a still frame of `doodle.gif` for reduced-motion
presentation. The `-transparent.png` files are the original artwork with its
white canvas removed.
